# CT Life current website direction

Updated 7 October 2026. Opening09 refines opening08, preserving the light canvas, original pastel character panels and transparent CT mark.

## Current hero

- Headline proposal: **Crypto Twitter turned into a game**. Each line has the same font, size and weight; there is no small introductory line.
- Supporting proposal: **Trade pretend coins and build projects with friends.** The original Claude artifact was read directly in the browser this turn. Its intended product centers on Crypto Twitter culture, fictional markets, player projects and social play. This copy describes that intended product, not verified implementation of every feature.
- Use DynaPuff at weight700 for the headline and existing wordmark, and Chakra Petch Medium for the supporting line. Both official font files and SIL OFL notices are bundled locally. Rebellion Squad and Phantom Guardians were studied as references; their free downloads are personal/noncommercial and are not embedded. The open-font alternatives were selected after comparing actual font renderings.
- Desktop copy aligns near the top of the character stage. Headline size exceeds all other type. Mobile retains the three-character row; tighter spacing accommodates the longer headline.
- Header contains the existing transparent mark/wordmark and **Get the game**. Daily Quests, Select Class and mobile Menu links are removed. The hero's existing **Get the game** button remains. Both native buttons are disabled because the user selected this wording with the destination pending. Do not invent a download URL.
- Native **Scroll Down** link targets `#life`. Its Icons8 iOS Down Arrow, icon41189, is the original50px transparent PNG displayed at22px. CSS animates only vertical movement by4px. Reduced-motion CSS disables animation. An Icons8 attribution link appears below the second section on each current page using the asset.
- There is no hero divider, footer slogan or quest CTA. The character caption says **Meet CT’s tribes**. The second section title is **A day in CT Life**. Other existing second-section interactions and copy remain.
- Retain the approved canvas, ink, muted text and panel colors. No character art was regenerated and no card color changed.
- No em dashes in current page copy.
