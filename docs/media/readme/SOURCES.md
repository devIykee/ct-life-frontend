Device originals are in the project’s external evidence archive. Hermes’s `exhaustive/RAILWAY-DEVICE.md` documents that run; the screenshots are historical captures, not evidence of a fresh build or multiplayer acceptance. The shown patrons are NPCs. The expanded character roster is not pictured as a finished feature.

The shipped [CT mark](../../../client/Assets/Resources/UI/Brand/ct-mark.png), Lilita One and Manrope fonts are reused. Font licences are in [`UI/Fonts`](../../../client/Assets/Resources/UI/Fonts); scene and model attribution remains in [art credits](../../../art/LICENSES.md).

The panels add typography, colour and frames around existing images. Gameplay UI is not repainted, populated with invented users, or retouched. Original source hashes and final file hashes are recorded in [manifest.json](manifest.json).
