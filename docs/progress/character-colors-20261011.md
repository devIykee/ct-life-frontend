# Supported character colors — 2026-10-11

Dex and Nova have reviewed region masks in Hermes's preserved v3 export. Their imported albedos are byte-identical to the source albedos associated with those masks. The two 1024-pixel masks per body independently address skin, hair, top, bottom, shoes, accent, brows and hat. Numeric inspection found nonempty supported channels and no overlapping mask0 regions. Four copied masks total 87,163 bytes; original source files remain untouched. Source hashes, tint-reference colors and the original palettes are recorded in `Assets/Art/characters/palettes/manifest.json`.

Snow/Rain's current production materials are baked atlases without an equivalent reviewed region-mask binding. Their existing authored outfit choices remain; this implementation does **not** claim independently editable colors for them. Creature and masked hero colors likewise remain unavailable until their masks/body/material binding is reviewed.

The new URP shader applies the preserved v3 linear-light tint formula through the exact selected channel. Unselected regions retain their authored albedo. Hair color derives a darker brow tint using the preserved v3 rule. Source textures and original materials are never modified. Every instance owns one selected-color material, shared by its crowd LODs and destroyed with the actor. `AvatarFactory` uses the same resolver for creator and world, so a selected color is not a preview-only effect.

The saved representation remains the existing seven IDs. For `B = ubc_m` or `ubc_f`, a complete supported look is `[skin, head_B, hair, top, bottom, shoes, acc_none]`. Skin is the unchanged authored `skin_tone3` or `skin_01` through `skin_10`. Each remaining editable slot is its unchanged `{slot}_B` ID or `{slot}_B__{swatch}`. Hair has twelve explicit swatches; top/bottom/shoes share sixteen cloth swatches. Regions mix independently. Unknown colors, mismatched body IDs, multiple suffixes, extras and other accessories are rejected. Default IDs keep the original material. There are no new identities or clothing geometry in this change.

Integration API: `CharacterPaletteCatalog.Load().FindBase(headId)` lists supported bodies; `PaletteFor("skin"|"hair"|"top"|"bottom"|"shoes")` supplies swatches; `CharacterPaletteResolver.TryResolve(look, out selection)` exposes the exact source look and resolved entry; `TryChange(look, region, swatchId, out changed)` changes one field. A null swatch resets only that region. Root integrated palette options as non-modular seven-ID changes, character ownership and restore checks, and browsing categories. The backend agent was given the identical finite grammar for server validation and capability reporting.
