# CT Life — game presentation and controls, 6 October 2026

This report supersedes the older mineral-interface checkpoint. It records a frontend quality pass, not completion of the six-phase game or backend integration. Actual device images are identified below; Blender evidence is kept separate.

## Implemented

- Signed-in home/lobby: original city-diorama illustration, actual profile cash/energy, dream/home cards, large city-entry action and five app shortcuts. The artwork is an illustration, not a screenshot of playable geometry.
- Shared game UI: blue/gold palette, Lilita One display type, Manrope body text, sourced filled/bold Phosphor icons, outlined raised buttons and visible pressed/focus states.
- Solana Mobile sign-in screen: wallet action only. The public demo-city button was removed. Explicit developer fixtures are compile-guarded and are not a public guest mode.
- Direct analog movement; drag strength selects walk/run. Optional arrow buttons save immediately and survive restarting the app. Arrow holds walk; outward drags run.
- Movement cancellation around menus and pause, ground-collider alignment, speed-driven animation and existing footsteps. Camera gesture capture is cleared when interrupted by screens/focus/pause.
- Timeline camera distance 24 → 18.5 while retaining framing/pitch/FOV; stronger existing radial contact shadow, without realtime character shadows.
- Lobby/Timeline music replaced with the licensed full arrangement of Kevin MacLeod's **Funky Chunk**, streamed and attributed. Runtime playback/mute checks are evidence of behavior, not listening approval. Seven further district arrangements are included; M3 and M4 pass the comprehensive native playback-state checks below.
- Two authored character choices: Snow-derived **Everyday** and Rain-derived **Breeze**, each with its own Humanoid skeleton, one material/atlas and separate creator/world geometry. These are two complete looks, not a finished diverse cast or interchangeable wardrobe.
