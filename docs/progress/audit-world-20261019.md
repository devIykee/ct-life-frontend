## Runtime changes

- `IslandStreamer.WaterSurfaceAt(x,z)` returns NaN on dry ground/no island, otherwise the highest exposed lake/river/sea surface. Inland water is captured from the exact rendered triangles (including river height gradients and lake edge extensions); a 32m spatial index filters triangles before exact barycentric lookup. Terrain masks water hidden by banks; sea exists only where terrain is below sea level. `IsWater(x,z,y)` explicitly handles NaN.
- `GroundHeight` remains terrain-only. Road/bridge/tunnel collider hits must take precedence in Feel recovery/landing logic. `IsReady` still distinguishes detailed streamed collision from the fallback. Existing `EnsureLoaded(position, radius, cancellationToken)` remains available.
- An always-loaded ground collider is generated in four 8m tiles before island load completes. It uses a conservative lower envelope (minimum surrounding fine samples, minus 0.15m), rather than corner sampling that would create invisible surfaces across carved roads/valleys. It preserves authored tunnel holes. This is a last-resort floor, not landing readiness or an exact terrain surface.
- Streaming permits one walking request or three fast-travel/vehicle requests. Prefetch reaches 250m ahead, clamped to 4–10 seconds. Three concurrent cell requests share the existing three terrain chunks per frame budget. `EnsureCells` fills up to three slots, and cancellation cleans up instantiated cells.
