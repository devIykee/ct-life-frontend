# CT Life logo (source of truth)

The glossy "CT" mark: mint-green T, cyan-to-purple C (Solana gradient colors), thick plum outline. Generated in the
user's Codex chat "Review CT Life game handoff" on 2026-10-06 with Codex's built-in image generation, then cut out
to a transparent background (see `transparent-background-edit.json`). The same files are used by the landing page
draft (`ct-life-evidence/website/draft-01/assets/brand/`). Lockup on the landing page: the mark + "CT LIFE" set in
DynaPuff (bold); supporting text in Chakra Petch Medium.
