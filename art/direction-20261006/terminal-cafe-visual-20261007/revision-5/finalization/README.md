# Art5 existing-bake finalization

The Art5 stage passed and the GPU light bake completed with3 maps/240 bindings, but its wrapper failed while creating a dictionary from eight same-named root siblings. All eight saved monitor witnesses use `Direction_monitor_triple`; their exact world positions and geometry digests are distinct. This was a finalization identity failure, not evidence that the lightmaps or geometry were invalid. The original failed `BakeReceipt.json` remains untouched.

Import only the two new manifest classes. Both compile exit0 against installed Editor references after output-flag audit; only their private /tmp DLLs are written by the compiler. Run `CTLife.EditorTools.CafeArt5BakeFinalization.FinalizeExistingBake` in root-owned idle batch. It does not rebuild, rebake, save or mutate a prefab, mesh, material, scene or registry. It pins the current baked prefab, original Art3, stage receipt, failed wrapper receipt and native LastBake report.

Each saved monitor position must match exactly one actual native monitor. The helper requires all eight original stage surface digests, unchanged non-monitor geometry/colliders/anchors/navigation, exact support and bracket corner attributes (position, normal, UV0), and original screen corner attributes plus the station's original texture reference. It does not weaken the old geometry comparison to approximate bounds. New lightmap UV2 is intentionally excluded from original UV0 equality.

A temporary preview clone manually installs the actual3 persistent maps/240 unique renderer bindings. Every actual renderer's map index, texture and scale/offset is checked; the old global table is restored before closing that owned preview. Protected physical assets are hashed before/after, with current installed-package path resolution. Success writes only a separate `BakeFinalizationReceipt.json` plus a temporary transaction. A failure leaves the old receipt intact and does not call automatic restore or global asset save. Any newly written success record is moved into the failure transaction if its final byte verification fails. Rehash protected inputs again after Editor exit.

After finalization passes, `CafeArtRoomReview5Finalized.Launch` reads the new receipt and also verifies the preserved failure hash. Use saved Bootstrap via `-openfile` alone and the manifest arguments. No asynchronous `-quit` or `-nographics`. It retains the original three tap/walk probes, front and rear monitor close-ups and actual room camera views. The finalizer is native data/binding verification, not visible art acceptance. Inspect clear screens, original art UV/readability, attached rear supports, base support and clean gameplay silhouette. Seating exits/voice/authority/device/registry acceptance remain separate.

Independent post-exit hash audits of the original runs: stage5,002 files unchanged, failed bake5,003 unchanged; reports are in the parent revision folder. No new Art version or redundant light bake is required if this strict finalizer and visual review pass.
