## Art and resource budget

Five original generated atlases contain 40 shots. Snow and Rain use the established character reference renders; Studio material/lighting language guided the fictional sets. These are generated still illustrations, **not gameplay recordings**, licensed third-party video, real people or real platform content. Exact prompt files, input references, hashes and source destinations are in `asset-source-manifest.json`. PNG source bytes total 9,354,172. The calculated RGBA32 upper estimate is 31,461,344 bytes; Android ASTC 6×6 block storage estimate is 3,508,128 bytes, excluding engine overhead. Runtime memory measurements are not yet available. Five atlases load before mounting; nine Image elements use those shared textures, with no per-frame texture/material allocation, new mesh, package or network call.

Atlas frame proportions are not uniform. Source crops are explicitly measured in `ClipCutStoryboard.cs`; generated divider strokes are excluded. The first story has portrait frames; later stories are wider. `Image.sourceRect` uses top-left coordinates, and `ScaleToFit` preserves each selected crop’s proportions instead of stretching it. [Unity Image sourceRect](https://docs.unity3d.com/6000.3/Documentation/ScriptReference/UIElements.Image-sourceRect.html), [Image scaleMode](https://docs.unity3d.com/6000.3/Documentation/ScriptReference/UIElements.Image-scaleMode.html), [current 6000.3 Image source](https://github.com/Unity-Technologies/UnityCsReference/blob/6000.3/Modules/UIElements/Core/Controls/Image.cs).

The isolated importer checks all five exact source hashes before writing, refuses different existing target PNGs, and touches only these resource importers. It uses sRGB, clamp/bilinear, no mipmaps/readable CPU copy, NPOT scale None and max size 2048. Editor references remain uncompressed; Android overrides use ASTC 6×6. Source dimensions and bytes are rechecked after import. It does not save any scene or globally save assets. The receipt reports actual imported dimensions/format and runtime texture memory. [Unity NPOT scaling](https://docs.unity3d.com/6000.3/Documentation/ScriptReference/TextureImporter-npotScale.html), [platform settings](https://docs.unity3d.com/6000.3/Documentation/ScriptReference/TextureImporterPlatformSettings.html), [ASTC 6×6](https://docs.unity3d.com/6000.3/Documentation/ScriptReference/TextureImporterFormat.ASTC_6x6.html), [scoped importer save](https://docs.unity3d.com/6000.3/Documentation/ScriptReference/AssetImporter.SaveAndReimport.html).
